# Bitcoin Security Watcher

[Bitcoin Security Watcher](https://sec.21ideas.org) — некоммерческий проект
[21ideas](https://21ideas.org), который помогает биткоинерам вовремя узнавать о важных
уязвимостях, утечках и других угрозах, способных привести к финансовым потерям или
проблемам с безопасностью.

Публикуется то, что требует действия или осведомлённости сегодня: баги кошельков и
прошивок аппаратных устройств, дыры в реализациях узлов, утечки персональных данных и
скомпрометированные пакеты в цепочке поставок.

## Как это работает

Бот [sec-watcher-bot](https://github.com/21ideas-org/sec-watcher-bot) следит за
анонсами, разбирает их и отбирает критические сигналы. Полный текст и обновления
инцидентов публикуются на сайте, а краткие оповещения — в Telegram. RSS-лента даёт
возможность читать публикации в ридере.

Проект развивается, но в вопросах безопасности своевременность важнее безупречной
полировки.

## Где читать

- [Сайт](https://sec.21ideas.org) — полный текст и обновления инцидентов.
- [RSS](https://sec.21ideas.org/rss.xml) — фид для ридеров.
- Telegram — краткие оповещения; ссылка на канал есть на сайте.
