# sec-web

Сайт [sec.21ideas.org](https://sec.21ideas.org) — критические security-оповещения
для биткоинеров. Канонический контент автоматически создаёт
[`sec-watcher-bot`](https://github.com/21ideas-org/sec-watcher-bot) create-only запросом
в `sec-web/main` через Contents API. И live, и `--dry-run` пишут сюда публичную страницу;
режим меняет только адресата парного Telegram-уведомления. После каждого push в `main`
Actions собирают и деплоят сайт на GitHub Pages.

Astro без фреймворков, статика.

```
npm install
npm run dev
```

## Фильтр по аудитории

Бейдж аудитории — ссылка на `/feed?audience=<id>` с каноническими ID `holders`,
`node_operators`, `developers`, `merchant_infra`. Несколько аудиторий задаются
повторением ключа (`/feed?audience=holders&audience=developers`) и совпадают по OR;
публикация показывается один раз. Отсутствие ключа и все четыре ID — одна и та же
лента без фильтра, и все четыре канонизируются обратно в адрес без ключа.
Нераспознанное значение даёт явное invalid-состояние со сбросом, а не тихую полную
ленту.

URL — источник правды: прямой переход, перезагрузка и «назад/вперёд» восстанавливают
и выбор, и выдачу. Компактный переключатель над лентой одинаков на десктопе и на
телефоне: правки в нём — черновик до кнопки «Выбрать», Escape и клик снаружи его
отменяют.

Словарь и нормализация живут только в `src/audience.ts`, логика запроса и совпадения —
в `src/audience-filter.ts`; браузерный скрипт импортирует их. Фильтрация клиентская
поверх уже отрендеренных строк: без JavaScript лента остаётся полной, и страница
говорит об этом прямо. Историческая разметка не переписывалась — legacy `all`, пустые
и неизвестные значения видны только в полной ленте. Хроники (`external`) в фильтр не
входят, RSS остаётся полным.
